How it works

ChatGPT: Extracts conversations from the DOM using stable data-message-author-role attributes.

Claude: Uses Claude's REST API (/api/organizations/{'{orgId}'}/chat_conversations) to capture full conversations including thinking blocks and tool calls that DOM scraping misses.

Storage: IndexedDB for conversation history (handles large datasets efficiently), with coalesced writes to avoid Chrome storage rate limits.

Architecture: Manifest V3 browser extension with event-driven service worker, quiescence detection for SPA stability (median 410ms vs 1500ms for fixed delays), and explicit cleanup patterns to prevent memory leaks.
